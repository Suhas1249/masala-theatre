## 🌟 Executive Summary

**MASALA THEATRE** rejects conventional static restaurant templates. Built as an award-style flagship web application for **AURAWEBS**, the website transforms high-end Indian fine dining into a multi-act theatrical performance. 

Instead of traditional standard navigation (`Hero → About → Menu → Contact`), the application engages visitors in a 5-Act culinary journey:

```text
       OVERTURE (Curtain Intro & Ember Canvas)
          ↓
  ACT I — FIRE & SMOKE (Interactive Tandoor Simulator)
          ↓
  ACT II — SPICE & ALCHEMY (Interactive Spice Wheel & Dish Unlock)
          ↓
  ACT III — THE DISH ("One Meal, One Journey" Farm-to-Table)
          ↓
  ACT IV — THE REPERTOIRE (Interactive Menu & Quick View)
          ↓
  FINAL ACT — ENCORE (Golden VIP Pass Ticket Booking)
```

## 🎭 The 5 Acts + Overture & Encore

### 1. OVERTURE — The Opening Performance
* **Interactive Velvet Curtain**: Parting curtain intro animation with glowing seal, soundscape controls, and loading progress bar.
* **Canvas Ember Physics**: Custom HTML5 Canvas engine generating floating spark and ember particle physics.
* **Editorial Aesthetics**: Oversized stroke typography, gold leaf accents, and signature 24k Gold Lamb Raan presentation.

### 2. ACT I — FIRE & SMOKE
* **Clay Tandoor Simulator**: Interactive furnace with heat particles that bend dynamically according to cursor position.
* **Temperature Controller**: Slider regulating heat from 200°C to 500°C, adjusting ember intensity, spark frequency, and heat glow.
* **Culinary Philosophy**: Explores searing mechanics at 450°C to seal natural juices and charcoal aromas.

### 3. ACT II — SPICE & ALCHEMY
* **Interactive Spice Wheel**: Tap to mix 6 royal spices (*🌶 Kashmiri Red Chili, 🌿 Green Elaichi, ⭐ Royal Saffron, 🌸 Star Anise, 🌾 Bhuna Cumin, 🌺 Cloves*).
* **Realtime Flavor Meter**: Calculates flavor notes (e.g. `SMOKY · ROYAL · INTENSE`).
* **Dish Unlock Engine**: Automatically unlocks customized signature dishes with instant **Add to Order** cart triggers.

### 4. ACT III — THE DISH ("One Meal, One Journey")
* **6-Stage Ingredient Journey**: Follows the physical transformation of ingredients through 6 interactive steps:
  1. *Farm & Terroir* (High-altitude Himalayan glacial soil)
  2. *Royal Harvest* (Dawn selection & solar curing)
  3. *Stone Mortar Grinding* (Granite cold friction milling)
  4. *Tandoor Charcoal Sear* (450°C clay oven flame)
  5. *18-Hour Dum Cooking* (Dough-sealed handi simmer)
  6. *24k Gold Plating* (Edible gold foil & microgreen dressing)

### 5. ACT IV — THE REPERTOIRE (Interactive Menu)
* **Categorized Menu**: Starters, Royal Mains, Breads & Rice, Sweet Finale.
* **Smart Filters**: Dietary toggles (*Vegetarian Only, Chef Specials*) and live search.
* **Quick View Modal**: Interactive 3D card tilt effects, spice level indicators, key ingredients, and Sommelier pairings.

### 6. FINAL ACT — ENCORE & RESERVATIONS
* **Performance Zone Selector**: Chef's Table (Front Row), Royal Booth Sanctuary, Garden Courtyard.
* **VIP Golden Ticket Generator**: Submitting a reservation fires golden confetti and renders a print-ready metallic VIP Pass.

## 💻 Tech Stack & Architecture

* **Core Framework**: React 18 + Vite (TypeScript)
* **Styling & System**: Tailwind CSS + Custom CSS Variables + Glassmorphism & Ember Glow Filters
* **Animation & Particle Physics**: HTML5 Canvas API + GSAP 3 + Canvas Confetti
* **Audio Engine**: Synthesized Web Audio API (Zero external MP3 file dependencies; works 100% offline)
* **Hosting Target**: GitHub Pages (1-click deployment via `npm run deploy`)

## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_GITHUB_USERNAME/masala-theatre.git
   cd masala-theatre
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run local development server**:
   ```bash
   npm run dev
   ```
   *Application will open at `http://localhost:3000/`*

4. **Deploy to GitHub Pages**:
   ```bash
   npm run deploy
   ```
